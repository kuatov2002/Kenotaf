# КЕНОТАФ

Дизельпанк-метроидвания на чистом JavaScript и Canvas 2D. Курьер поднимается из Отстойника
подземной аркологии к Печати, которую двести лет никто не открывал.

## Запуск

Открыть `index.html` в браузере. Сервер и сборка не нужны, работает и по двойному клику (`file://`).

## Управление

| Клавиши | Действие |
|---|---|
| A / D · ← → | движение |
| SPACE | прыжок, удержание — выше; у рифлёной стены — кошки; под латунью — магнит |
| J / X / ЛКМ | удар ключом; с ↑ — вверх; в прыжке с ↓ — вниз с отскоком |
| K / C / ПКМ | импульс резака |
| L / SHIFT / Z | рывок, на время рывка неуязвим |
| Q / I (держать) | залатать куртку за РЕМОНТ (копится ударами) |
| S / ↓ | присед, на бегу — подкат |
| E / F | двери, рычаги, сальваж; у фонаря — отдых |
| ESC | пауза и карта (TAB — весь мир) |
| M · F1 · F2 | звук · отладка · респаун |

## Структура

```
index.html          разметка, порядок скриптов
css/style.css
js/core/            утилиты, конфиг, ввод, звук, физика, сохранение
js/render/          текстуры, процедурный арт (Kit, Art), частицы, камера, рендер
js/world/           комнаты по зонам (rooms/z1…z5), системы, карта, пневмопочта
js/entities/        игрок, враги, боссы, бой
js/ui/              HUD, карта, сцены, обучение
js/dev/             аудит проходимости и отладочная панель (F1)
tools/              автотесты и упаковка
docs/DESIGN.md      дизайн-документ: мир, гейты, секреты, бой
```

Скрипты подключены классическими `<script>`, без ES-модулей: иначе игра не запустится по `file://`.

## Проверки

Нужен Playwright с Chromium (`npm i -g playwright`).

```
node tools/smoke.js       # каждая комната: загрузка, 5 с случайного ввода, точки прибытия у дверей
node tools/progress.js    # решатель прогрессии: без любой способности финал недостижим
```

## Публикация на itch.io

```
node tools/pack.js        # → dist/kenotaf-itch.zip
```

На itch.io: Kind of project — HTML, загрузить zip, отметить «This file will be played in the browser»,
размер окна 1280×720, включить кнопку полноэкранного режима. Обложка, баннер и скриншоты лежат
в `screenshots/` и `screenshots/itch/`.
